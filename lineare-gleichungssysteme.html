Lineare
Gleichungssysteme

Grundlagen

Ein lineares Gleichungssystem besteht aus zwei Gleichungen mit zwei Unbekannten (meist x und y). Die Lösung ist das Zahlenpaar, das beide Gleichungen gleichzeitig erfüllt – geometrisch der Schnittpunkt zweier Geraden.

Beispiel Schritt für Schritt (Einsetzungsverfahren): y = x + 3 und 2x + y = 15.

1. y in die zweite Gleichung einsetzen: 2x + (x + 3) = 15
2. Zusammenfassen: 3x + 3 = 15
3. Lösen: 3x = 12, also x = 4
4. x in y = x + 3 einsetzen: y = 4 + 3 = 7

Beim Additionsverfahren addierst oder subtrahierst du beide Gleichungen so, dass eine Variable wegfällt.

Beispiel Schritt für Schritt (Additionsverfahren): x + y = 10 und x − y = 2.

1. Beide Gleichungen addieren: (x + y) + (x − y) = 10 + 2
2. Die y-Glieder heben sich auf: 2x = 12
3. Lösen: x = 6
4. x in x + y = 10 einsetzen: y = 10 − 6 = 4

Merke

Einsetzungsverfahren: eine Variable durch die andere ersetzen.
Additionsverfahren: Gleichungen so addieren oder subtrahieren, dass eine Variable wegfällt.
Am Ende immer den gefundenen Wert in eine der Gleichungen einsetzen, um die zweite Variable zu bestimmen.

1Aufgabe 1

y = x + 3 und 2x + y = 15. Wie groß ist x?
Lösung anzeigen
Ergebnis: x = 4
  1. y in die zweite Gleichung einsetzen: 2x + (x + 3) = 15.
  2. Zusammenfassen: 3x + 3 = 15.
  3. Lösen: 3x = 12, also x = 4.
Typischer Fehler: Beim Einsetzen die gesamte rechte Seite von y (also x + 3) in Klammern einsetzen, nicht nur einen Teil.

2Aufgabe 2

y = x + 3 und 2x + y = 15. Wie groß ist y?
Lösung anzeigen
Ergebnis: y = 7
  1. Aus Aufgabe 1 wissen wir: x = 4.
  2. x in y = x + 3 einsetzen: y = 4 + 3.
  3. Ergebnis: y = 7.
Typischer Fehler: Nach dem Finden von x nicht vergessen, y auch wirklich zu berechnen.

3Aufgabe 3

x + y = 10 und x − y = 2. Wie groß ist x?
Lösung anzeigen
Ergebnis: x = 6
  1. Beide Gleichungen addieren: (x + y) + (x − y) = 10 + 2.
  2. Die y-Glieder heben sich auf: 2x = 12.
  3. Lösen: x = 6.
Typischer Fehler: Beim Addieren heben sich +y und −y gegenseitig auf – deshalb funktioniert das Additionsverfahren hier so gut.

4Aufgabe 4

x + y = 10 und x − y = 2. Wie groß ist y?
Lösung anzeigen
Ergebnis: y = 4
  1. Aus Aufgabe 3 wissen wir: x = 6.
  2. x in x + y = 10 einsetzen: 6 + y = 10.
  3. Auf beiden Seiten 6 abziehen: y = 4.
Typischer Fehler: Man kann x auch in die zweite Gleichung einsetzen, das Ergebnis für y bleibt dasselbe.

5Aufgabe 5

3x + y = 16 und y = x. Wie groß ist x?
Lösung anzeigen
Ergebnis: x = 4
  1. y in die erste Gleichung einsetzen: 3x + x = 16.
  2. Zusammenfassen: 4x = 16.
  3. Auf beiden Seiten durch 4 teilen: x = 4.
Typischer Fehler: Wenn y = x gilt, kann man y direkt durch x ersetzen und hat nur noch eine Variable.

6Aufgabe 6

3x + y = 16 und y = x. Wie groß ist y?
Lösung anzeigen
Ergebnis: y = 4
  1. Aus Aufgabe 5 wissen wir: x = 4.
  2. Da y = x gilt, ist y ebenfalls 4.
  3. Ergebnis: y = 4.
Typischer Fehler: Wenn zwei Variablen laut Angabe gleich sind, haben sie am Ende auch denselben Zahlenwert.

7Aufgabe 7

Zwei Zahlen haben die Summe 20 und die Differenz 4. Das Gleichungssystem lautet x + y = 20, x − y = 4. Wie groß ist x?
Lösung anzeigen
Ergebnis: x = 12
  1. Beide Gleichungen addieren: (x + y) + (x − y) = 20 + 4.
  2. Die y-Glieder heben sich auf: 2x = 24.
  3. Auf beiden Seiten durch 2 teilen: x = 12.
Typischer Fehler: Aus einer Textaufgabe zuerst korrekt das Gleichungssystem ableiten, dann erst rechnen.

8Aufgabe 8

Ein Erwachsenenticket kostet x Euro, ein Kinderticket y Euro. Es gilt x = 2y. 3 Erwachsene und 2 Kinder kosten zusammen 3x + 2y = 40 Euro. Wie viel kostet ein Kinderticket (y)?
Lösung anzeigen
Ergebnis: 5 Euro
  1. x = 2y in die zweite Gleichung einsetzen: 3 · (2y) + 2y = 40.
  2. Zusammenfassen: 6y + 2y = 40, also 8y = 40.
  3. Auf beiden Seiten durch 8 teilen: y = 5.
Typischer Fehler: Beim Einsetzen von x = 2y sorgfältig 3 · 2y = 6y rechnen, nicht nur 3 · 2.
