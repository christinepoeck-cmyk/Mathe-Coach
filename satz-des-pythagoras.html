Luisen-Gymnasium · Klasse 9

Satz des
Pythagoras

Grundlagen

In jedem rechtwinkligen Dreieck gilt: Das Quadrat über der Hypotenuse (der längsten Seite, gegenüber dem rechten Winkel) ist genauso groß wie die Summe der Quadrate über den beiden Katheten. Formel: a² + b² = c².

Beispiel Schritt für Schritt: Rechtwinkliges Dreieck mit a = 3 und b = 4. Berechne c.

1. Formel: a² + b² = c²
2. Einsetzen: 3² + 4² = c²
3. Rechnen: 9 + 16 = 25, also c² = 25
4. Wurzel ziehen: c = √25 = 5

Wenn eine Kathete gesucht ist, stellst du die Formel um: a² = c² − b² (bzw. b² = c² − a²).

Beispiel Schritt für Schritt: Rechtwinkliges Dreieck mit c = 13 und a = 5. Berechne b.

1. Formel umstellen: b² = c² − a²
2. Einsetzen: b² = 13² − 5² = 169 − 25
3. Rechnen: 169 − 25 = 144
4. Wurzel ziehen: b = √144 = 12

Merke

a² + b² = c², wobei c immer die Hypotenuse ist (gegenüber dem rechten Winkel).
Kathete gesucht: Katheten-Quadrat = Hypotenusen-Quadrat minus anderes Katheten-Quadrat.
Am Ende immer die Wurzel ziehen, um die Seitenlänge zu erhalten.

1Aufgabe 1

Rechtwinkliges Dreieck mit a = 3 und b = 4. Wie lang ist c?
Lösung anzeigen
Ergebnis: c = 5
  1. Formel: c² = a² + b².
  2. Einsetzen: c² = 3² + 4² = 9 + 16 = 25.
  3. Wurzel ziehen: c = √25 = 5.
Typischer Fehler: Zuerst beide Katheten quadrieren und addieren, dann erst die Wurzel ziehen.

2Aufgabe 2

Rechtwinkliges Dreieck mit a = 6 und b = 8. Wie lang ist c?
Lösung anzeigen
Ergebnis: c = 10
  1. Formel: c² = a² + b².
  2. Einsetzen: c² = 6² + 8² = 36 + 64 = 100.
  3. Wurzel ziehen: c = √100 = 10.
Typischer Fehler: c ist immer die längste Seite und liegt dem rechten Winkel gegenüber.

3Aufgabe 3

Rechtwinkliges Dreieck mit a = 5 und b = 12. Wie lang ist c?
Lösung anzeigen
Ergebnis: c = 13
  1. Formel: c² = a² + b².
  2. Einsetzen: c² = 5² + 12² = 25 + 144 = 169.
  3. Wurzel ziehen: c = √169 = 13.
Typischer Fehler: 5, 12, 13 ist ein bekanntes Zahlentripel, das oft in Aufgaben vorkommt.

4Aufgabe 4

Rechtwinkliges Dreieck mit c = 13 und a = 5. Wie lang ist b?
Lösung anzeigen
Ergebnis: b = 12
  1. Formel umstellen: b² = c² − a².
  2. Einsetzen: b² = 13² − 5² = 169 − 25 = 144.
  3. Wurzel ziehen: b = √144 = 12.
Typischer Fehler: Ist eine Kathete gesucht, wird subtrahiert, nicht addiert.

5Aufgabe 5

Rechtwinkliges Dreieck mit c = 25 und a = 7. Wie lang ist b?
Lösung anzeigen
Ergebnis: b = 24
  1. Formel umstellen: b² = c² − a².
  2. Einsetzen: b² = 25² − 7² = 625 − 49 = 576.
  3. Wurzel ziehen: b = √576 = 24.
Typischer Fehler: c ist immer die längste Seite und wird beim Umstellen der Formel niemals einfach abgezogen.

6Aufgabe 6

Rechtwinkliges Dreieck mit c = 10 und b = 6. Wie lang ist a?
Lösung anzeigen
Ergebnis: a = 8
  1. Formel umstellen: a² = c² − b².
  2. Einsetzen: a² = 10² − 6² = 100 − 36 = 64.
  3. Wurzel ziehen: a = √64 = 8.
Typischer Fehler: 6, 8, 10 ist das Zahlentripel 3, 4, 5 mit dem Faktor 2 multipliziert.

7Aufgabe 7

Eine Leiter lehnt an einer Wand. Der Fuß der Leiter ist 3 m von der Wand entfernt, die Leiter ist 5 m lang. Wie hoch reicht die Leiter an der Wand (in m)?
Lösung anzeigen
Ergebnis: 4 m
  1. Die Leiter ist die Hypotenuse (c = 5), der Abstand zur Wand eine Kathete (a = 3).
  2. Formel umstellen: b² = c² − a² = 5² − 3² = 25 − 9 = 16.
  3. Wurzel ziehen: b = √16 = 4.
Typischer Fehler: Bei Sachaufgaben zuerst überlegen, welche Größe die Hypotenuse ist (meist die schräge Strecke).

8Aufgabe 8

Ein Fernsehbildschirm ist 24 Zoll breit und 18 Zoll hoch. Wie groß ist die Diagonale (in Zoll)?
Lösung anzeigen
Ergebnis: 30 Zoll
  1. Breite und Höhe sind die Katheten, die Diagonale ist die Hypotenuse.
  2. Formel: c² = 24² + 18² = 576 + 324 = 900.
  3. Wurzel ziehen: c = √900 = 30.
Typischer Fehler: Die Bildschirmdiagonale bildet mit Breite und Höhe ein rechtwinkliges Dreieck, deshalb funktioniert der Satz des Pythagoras hier.
